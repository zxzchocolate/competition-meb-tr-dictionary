# Turkish 50 — TR / EN Dictionary

A 50-entry Turkish–English word list with individual HTML pages.

## Features
- Search the index in Turkish or English.
- Open a dedicated page for each word.
- English equivalents are concise learner translations.
- Turkish explanations are stored in the bundled `dictionary-data.js` database.
- Word pages work offline after the site files have been downloaded.
- Each entry links to TDK as an external reference; TDK is not queried by the site.
- Responsive editorial layout; plain HTML, CSS and JavaScript.

## Data and attribution
The Turkish explanations are part of the site's local, curated learner database. They are not live TDK API responses or verbatim official dictionary entries. English equivalents are learner translations. The TDK website is linked as an optional reference.

The list is a practical learner-focused selection, not a statistically verified corpus-frequency ranking.

## Run locally
Open `index.html` in a browser. Search and word definitions run from local files; no API key, network request, or TDK service is required.

## GitHub Pages
The workflow deploys the static site from `main`. If needed, select **Settings → Pages → Build and deployment → Source → GitHub Actions**.
